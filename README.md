# Ubunifu Connect

A modern web application for the Ubunifu Foundation, built with React, Vite, and Shadcn UI.

## Local Setup

This project is a standalone local application. To get started, follow these steps:

1. **Prerequisites**: Ensure you have [Node.js](https://nodejs.org/) installed on your machine.
2. **Installation**: Open your terminal in this directory and install the necessary dependencies:
   ```bash
   npm install
   ```
3. **Development**: Start the local development server:
   ```bash
   npm run dev
   ```
4. **Building for Production**: To create a production build, run:
   ```bash
   npm run build
   ```

## Project Structure

- `src/`: Contains the source code including components, pages, and data.
- `public/`: Static assets like images and videos.
- `components.json`: Configuration for Shadcn UI components.
- `tailwind.config.js`: Tailwind CSS configuration.
- `vite.config.js`: Vite build configuration.
